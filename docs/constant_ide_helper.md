# Генерация определений констант для IDE

`Hipot\Utils\ConstantIdeHelper` создаёт PHP-файл с определениями пользовательских констант, появившихся во время выполнения отдельного участка кода. Такой файл индексируется IDE и добавляет автодополнение, переход к определению и сведения о типах для констант Bitrix-проекта.

Помощник не подключает созданный файл во время выполнения приложения. Это вспомогательный файл для статического анализа: рабочие значения констант по-прежнему определяет исходный код проекта.

## Использование

```php
<?php

use Bitrix\Main\Loader;
use Hipot\Utils\ConstantIdeHelper;

$fileCache = Loader::getDocumentRoot()
	. '/local/php_interface/ide-helper-cache/constants.php';

$helper = ConstantIdeHelper::getInstance();
$helper->start();

foreach ($arConstants as $constName => $constValue) {
	if (!defined($constName)) {
		define($constName, $constValue);
	}
}

// finish() сохраняет файл только при его отсутствии. Удаляем устаревшую
// версию после изменения этого исходного файла, чтобы создать её заново.
if (
	is_file($fileCache)
	&& filemtime(__FILE__) > filemtime($fileCache)
) {
	unlink($fileCache);
}

$helper->finish($fileCache);
unset($helper);
```

На первом запуске файла кеша ещё нет, поэтому проверка `is_file()` перед `filemtime()` и `unlink()` обязательна. Родительские каталоги создаются через функцию Bitrix `CheckDirPath()`.

## Как работает захват

Вызов `start()` запоминает пользовательские константы, которые уже определены в PHP-процессе. `getDefined()` возвращает разницу между текущим набором констант и этим снимком. `finish()` формирует определения только для этой разницы:

```php
/**
 * CATALOG_IBLOCK_ID
 * @var integer
 */
define('CATALOG_IBLOCK_ID', 7);
```

Если целевой файл существует, `finish()` завершает работу без изменений. Такое поведение позволяет не записывать один и тот же файл при каждом запросе. Удалять его следует при изменении источника констант, во время сборки проекта либо вручную.

## Ограничения

- Между `start()` и `finish()` должен находиться только код, определения которого требуется добавить в IDE-файл. Все другие созданные в этот момент пользовательские константы тоже попадут в результат.
- Класс использует singleton и хранит один снимок. Вложенные или одновременно выполняемые сеансы захвата не поддерживаются.
- Массивы записываются в виде сериализованной строки с PHPDoc-типом `array`. Поэтому сгенерированный файл предназначен для индексации IDE и не должен подключаться для получения рабочих значений.
- Каталог кеша должен быть доступен PHP-процессу для записи. Сам файл обычно можно исключить из Git, если он генерируется в каждом окружении.
