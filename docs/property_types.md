# Дополнительные типы свойств

Файл `src/lib/handlers/property_types.php` подключается из `src/lib/handlers_add.php`
и регистрирует три типа через совместимые со старым API события Bitrix.
Классы загружаются штатным PSR-4 автозагрузчиком Hipot.

| Тип | Класс | Идентификатор |
| --- | --- | --- |
| Пользовательское поле: привязка к пользователю | `Hipot\UserField\UserType` | `hipot_user` |
| Пользовательское поле: HTML / визуальный редактор | `Hipot\UserField\HtmlType` | `hipot_html` |
| Свойство инфоблока: привязка к элементам с описанием | `Hipot\BitrixUtils\Iblock\ElementDescriptionType` | `hipot_element_description` |

## Привязка к пользователю

Поддерживает одиночные и множественные значения, выбор пользователя в административной
форме, редактирование списка и публичные callbacks. Хранит целочисленный ID пользователя;
перед сохранением проверяет корректность ID и существование пользователя.
Пустые значения сохраняются как `null`; обязательность проверяет менеджер полей Bitrix.

## HTML

Хранит HTML как строку, поддерживает одиночные и множественные значения.
Использует `CHTMLEditor` из модуля `fileman`; при его отсутствии выводит textarea.
Настройки строкового поля Bitrix сохраняются, число строк редактора — не менее восьми.
Имена контролов с индексами передаются редактору без замены, а DOM ID редакторов уникальны.

Публичный просмотр возвращает сохранённый HTML. Административный список показывает
экранированный текст без тегов.

## Привязка к элементам с описанием

Тип хранится как обычная связь `E`, поэтому стандартные операции Bitrix с привязками
и поле `DESCRIPTION` продолжают работать. При настройке свойства выберите связанный
инфоблок и включите «Выводить поле для описания значения» (`WITH_DESCRIPTION = Y`).
Множественность задаётся стандартной настройкой свойства. Для каждой связи выводятся
ID, кнопка выбора элемента, описание и название связанного элемента.
