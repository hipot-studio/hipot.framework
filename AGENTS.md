# Инструкции для агентов

## Обязательный контекст

Перед использованием API `hipot.framework`, изменением существующего кода или генерацией нового кода на основе фреймворка полностью прочитайте корневой [README.md](README.md).

Используйте `README.md` как основную карту возможностей и архитектурных соглашений проекта. Затем откройте только относящиеся к задаче документы, на которые он ссылается, включая документацию компонентов, сервисов, утилит и правила оформления кода.

Не определяйте контракт класса, метода или компонента только по его имени либо примеру использования. Перед генерацией кода сверяйте параметры, возвращаемые данные и ограничения с актуальной реализацией в `lib/`, `install/components/` и других указанных в `README.md` исходниках.

Если пример или документация расходятся с текущей реализацией, опирайтесь на реализацию и явно отмечайте найденное расхождение.
