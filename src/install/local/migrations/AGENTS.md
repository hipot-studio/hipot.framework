# Завершение миграций

Команда пользователя «миграция выполнена» (или явное сообщение об успешном выполнении) означает, что соответствующую миграцию нужно пометить как выполненную:

1. Добавить в начале PHP-файла `return 'Its Runed!';` перед исполняемым кодом миграции, сохраняя корректное расположение `declare`, `use` и проверки пролога.
2. Добавить к имени файла префикс времени подтверждения в формате `YYYYMMDD_HHMMSS_` (часовой пояс пользователя, по умолчанию Europe/Chisinau). Описательную часть имени сохранить. Уже имеющийся префикс повторно не добавлять.
3. Обновить ссылку на имя файла в примере запуска внутри миграции и другие ссылки проекта, если они есть.
4. Проверить синтаксис PHP после изменения.

Не помечать миграцию выполненной до подтверждения пользователя. Если из контекста нельзя определить миграцию, уточнить её имя.
